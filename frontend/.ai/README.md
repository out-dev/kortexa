# Frontend AI context

This folder contains frontend-specific agent context. Read the repository root
`AGENTS.md` first, then `frontend/AGENTS.md` for mandatory React rules.

## Contents

- `architecture/`: feature boundaries and frontend data flow.
- `workflows/`: repeatable frontend implementation procedures.
- `conventions/`: React, TypeScript, shadcn, TanStack, and testing conventions.
- `skills/`: frontend-specific reusable task instructions.

The generic architecture reference is maintained in
`docs/source/architecture/feature-based-architecture.rst`.
