# Backend AI context

This folder contains backend-specific agent context. Read the repository root
`AGENTS.md` first, then `backend/AGENTS.md` for mandatory Python rules.

## Contents

- `architecture/`: backend boundaries and dependency direction.
- `workflows/`: repeatable backend implementation procedures.
- `conventions/`: Python, testing, and uv conventions.
- `skills/`: backend-specific reusable task instructions.

The generic architecture reference is maintained in
`docs/source/architecture/hexagonal-architecture.rst`.
